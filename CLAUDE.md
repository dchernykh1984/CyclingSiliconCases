# CyclingSiliconCases — чехлы для велокомпьютеров Garmin

Исходные модели чехлов скачаны готовыми и лежат в `input_data/`. Наши правки
к ним — модели OpenSCAD в `src/cycling_cases/assets/models/`, которые
импортируют чужую сетку и делают с ней своё. Готовые STL собирает CI
и прикладывает к релизу. Python 3.11–3.13, uv, numpy, OpenSCAD.

## Правила, которые не обсуждаются

- **Коммит — одна строка.** Без тела, без `Co-Authored-By`, без упоминания
  Claude или соавторства. На это стоит хук в `.claude/settings.json`.
- **В репозитории только код и исходники.** Собранные STL, превью и zip
  не коммитятся — их делает CI.
- **Исходники — это исходный код.** `input_data/*.stl` скачаны готовыми,
  пересобрать их не из чего, поэтому они лежат в git и защищены тестом:
  подмена файла ломает приёмку с конкретными цифрами.
- **Геометрия проверяется расчётом, а не на глаз.** Всё, что должно
  поместиться на деталь, считается в `tests/` — рендер идёт второй
  проверкой, а не первой. Причина простая: на картинке надпись, уехавшая
  за кромку на полмиллиметра, не отличается от лежащей впритык.
- **Чужую форму не меняем молча.** Откуда модель и на каких условиях —
  в `input_data/README.md`. Если условия запрещают то, что мы собираемся
  сделать, об этом надо сказать вслух, а не молча сделать.
- **Чехлы между собой не связаны.** Общие у них только утилиты. Новый чехол
  — это файл в `input_data`, запись в `CASES` и, если нужно, своя модель.

## Где детали

| Скилл | О чём |
| --- | --- |
| `shipping-changes` | ветки, коммиты, пулл-реквесты, CI, релизы через release-please |
| `case-models` | как править чужую сетку в OpenSCAD: гравировка, переделка корпуса, печать |
| `mesh-checks` | измерительный инструмент: тела, сечения, отступы, замкнутость |
| `input-models` | что лежит в каждом исходнике: тела, размеры, назначение |

## Быстрые факты

- `make install`, дальше `make test`, `make lint`, `make typecheck`,
  `make build`, `make preview`, `make inspect`.
- Тесты: `uv run pytest`. Проверки перед коммитом идут сами — pre-commit
  гоняет ruff, mypy, гигиену файлов и стиль заголовка коммита.
- Версию проставляет release-please; в `pyproject.toml` она `dynamic`,
  иначе `uv.lock` устаревал бы на каждом релизном PR.
- OpenSCAD нужен только для чехлов со своей моделью и для превью. Путь
  к нестандартной сборке задаётся переменной `OPENSCAD`.
